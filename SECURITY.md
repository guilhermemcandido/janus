# Security Policy

Janus is a solo-maintained portfolio project simulating a financial exchange. It doesn't handle real funds, real user accounts, or connect to any real market - so the stakes here are different from a production system, but genuine issues (something that could crash the server, corrupt engine state, or a vulnerability pattern worth flagging) are still worth reporting.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting instead of a public issue: open the **Security** tab on this repo, then **Report a vulnerability**. That keeps details private until there's a fix.

## Response

This is a solo-maintained project with no formal SLA, but reports will be read and responded to.
